# Scope and Authorization

- Target: OWASP Juice Shop (intentionally vulnerable training app)
- Location: my own Kali VM, Docker container, http://127.0.0.1:3000 (not exposed to any network)
- Authorization: self-owned lab; Juice Shop is built for security practice
- In scope: the web app and its REST API on 127.0.0.1:3000
- Out of scope: any other host, site or network
- Rules: no testing against real systems; evidence stored locally in this repo
- Tools: Firefox, Burp Suite Community, curl
